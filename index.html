My story

  1. Chapter 1

    The darkroom

    Every photograph starts as nothing: a blank sheet in a dark room, waiting for light. So did I.

  2. Chapter 2

    Trapped in the machine

    Then came the code. Builds that broke at 3am, errors I couldn't read, tutorials that stopped working halfway. For a while, the software owned me.

  3. Chapter 3

    Breaking out

    I stopped fighting the code and started designing systems. One project, then ten, then more than two hundred. The walls came down.

  4. Chapter 4

    The AI Godfather

    Then I started building things that think: agents that plan, research, write code and check each other's work. I don't just write software anymore. I raise it.

  5. Chapter 5

    Toward superintelligence

    Every system I ship is a step toward AI that's smarter than the problems we hand it. That's where I'm heading, and I'm taking my clients with me.

How I got here

I started where most AI builders start: deep inside language models, tuning prompts and wiring together the first multi-agent frameworks. Now I build the whole thing, from the AI backend to the interface people actually touch.

  1. 2024

    Inside the models

    LLM tuning, prompt pipelines and my first multi-agent pipeline in production.

  2. 2025

    Full-stack

    Started building the products around the agents: web apps, WebGL and GSAP interfaces, Telegram bots and Android apps.

  3. 2026

    Independent, then a team

    Went full-time with direct clients, then founded The Code Bros to take on projects bigger than one person.
